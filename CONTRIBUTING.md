# Contributing to Complexity Analyzer

Thank you for your interest in contributing! We welcome bug reports, feature suggestions, and pull requests.

## Reporting Bugs
Please open an issue on the [Issues Page](https://github.com/dertex909/Complexity-Analyzer/issues), providing as much detail as possible, including:
- Minecraft Version
- Mod Version
- A clear description of the bug
- Steps to reproduce it
- Any relevant logs or crash reports.

## Suggesting Features
We'd love to hear your ideas! Please open a new issue or start a discussion on the [Discussions Page](https://github.com/dertex909/Complexity-Analyzer/discussions) to describe your suggestion.

## Submitting Code (Pull Requests)
1. Please discuss your proposed changes in an issue before starting to work on them.
2. Fork the repository and create a new branch for your feature.
3. Ensure your code follows the existing style and includes the LGPL-3.0 license header.
4. Submit a pull request with a clear description of your changes.
