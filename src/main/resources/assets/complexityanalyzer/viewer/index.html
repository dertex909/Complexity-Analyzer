About

This viewer reads a binary .cabin snapshot produced by the Complexity Analyzer mod.

  • Format version: 1.1
  • Compression: deflate-raw per-section, decompressed via the browser's native DecompressionStream.
  • Indices are kept uncompressed for O(log n) binary search and instant random access.
  • No external dependencies — no CDN, no fonts, no trackers.

Press Ctrl+K to focus global search. Sorting is stable; filters persist in the URL.
